# Task briefs for coding agents

Each brief describes one piece of work that a coding agent can do on its own branch while other work goes on.
Read [AGENTS.md](../../AGENTS.md) first: its rules and checklist apply to every brief.

There are no open briefs. Completed work is recorded in the [roadmap](../../ROADMAP.md) and
[architecture decisions](../adr/README.md).

For a new brief, name its roadmap item, reserve its ADR number and describe the acceptance criteria.
Work on a new branch from main, with one pull request per part. Delete the brief and its index entry in
the pull request that finishes it.
