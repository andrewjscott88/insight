# Task briefs for coding agents

Each brief describes one roadmap item that a coding agent can build on its own branch while other work goes on.
Read [AGENTS.md](../../AGENTS.md) first: its rules and checklist apply to every brief.

> Read AGENTS.md, then implement docs/briefs/tip-4.7-adversary-library-imports.md. Work on a new branch from
